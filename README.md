# Tacontudo - Site 1

Vitrine e landing page para a Tacontudo.

## Stack
- React 19
- TypeScript
- Vite 8
- Tailwind CSS 4
- Three.js (para animações/experiências imersivas)

## Como rodar
1. Instale as dependências: `npm install`
2. Rode o servidor de desenvolvimento: `npm run dev`
3. Para build de produção (multi-page): `npm run build`
4. Para rodar a suite de testes: `npm run test`

## Scripts
- `npm run lint`: Roda o ESLint
- `npm run test`: Roda a suite de testes unitários (Vitest)
- `npm run test:watch`: Roda a suite de testes unitários em modo watch (Vitest)
- `npm run preview`: Pré-visualiza o build de produção localmente
